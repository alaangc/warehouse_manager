# T135 — Continuous integration

Validation date: 2026-09-14. Local host: macOS arm64, Node 24.20.0,
pnpm 10.28.1, Playwright 1.62.1, Docker 29.7.2, PostgreSQL 18.6.

## Implemented gates

`.github/workflows/ci.yml` runs on pull requests, pushes to main, and manual
dispatch. Fresh Ubuntu 24.04 jobs use the pinned Node/pnpm toolchain and frozen
lockfile. API and web builds run in separate jobs. Unit/component tests, API
contract tests, PostgreSQL integration tests, existing contract lint/freshness
checks, migration/recovery drills, and each browser project have explicit gates.
Vitest workers are limited to two; each browser job uses one isolated stack.

The aggregate `CI required` check requires every dependency to succeed, including
all matrix members. Jobs have timeouts and obsolete runs are cancelled. Third-party
actions use immutable commit hashes, the token has read-only contents access,
checkout does not retain credentials, and no application secrets are supplied.
Browser diagnostics are uploaded separately per browser with seven-day retention.
There are no deployment, branch-protection mutation, or release-signing steps.

## Full-suite defects corrected

Running the whole suite exposed issues that isolated test-file runs did not:

- Administration changed the shared timezone and polluted later report assertions.
  It now restores the original setting in `finally`, with a reason and current
  version obtained through the UI.
- Old tests assumed banner navigation links and a `collection` URL parameter that
  the current screen does not use. Tests now use current routes and history tabs.
- Shared document setup used a module-level hook that did not attach to every
  importing spec. A per-context fixture now installs language and isolated API
  routing for every document test.
- Firefox exposed mobile grid overflow with long usernames. The user directory
  permits grid children to shrink and wraps long identifiers; the browser test now
  creates an unbroken long name and retains its no-horizontal-overflow assertion.
- Administration now follows the dashboard's Users link instead of forcing an
  immediate document navigation while dashboard requests are still loading.
- Screenshots use Playwright's per-test output directory, preventing browser
  overwrites and including them in CI artifacts. Isolated document storage uses
  a unique temporary directory removed with its owning stack.
- One existing inventory-query formatting issue was corrected without behavior
  changes so the repository-wide format gate passes.

## Review and limits

Constitution compliance review for this task: API authority, transactional rules,
exact arithmetic, and business history are unchanged. Tests still assert denied
access, immutable history, retries, and output isolation; failures were repaired,
not disabled. Application changes are limited to responsive user-directory layout.
The spec-quality checklist remains unchanged (16 checked, zero unchecked).

Hosted GitHub Actions execution has not been observed locally. The owner must make
`CI required` a required branch check after the workflow is pushed. This evidence
does not mark T133 physical-printer acceptance, T140 release cross-browser
acceptance, T141 participant usability, or T145 release sign-off complete.
Existing MUI development-console warnings, Kysely orderBy deprecation notices,
and the Vite bundle-size warning remain visible rather than suppressed.
